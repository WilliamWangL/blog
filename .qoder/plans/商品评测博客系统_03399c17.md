# 商品评测博客系统开发规划

## 技术栈选型

### 后端 (Java)
- **JDK**: 21 (LTS，虚拟线程支持)
- **框架**: Spring Boot 3.2+
- **数据库**: MySQL 8.0
- **ORM**: MyBatis-Plus (简化CRUD)
- **安全**: Spring Security + JWT
- **缓存**: Redis
- **搜索**: MySQL 全文索引 (使用 MATCH AGAINST)
- **文件存储**: 本地/MinIO/OSS
- **API文档**: SpringDoc OpenAPI

### 前端
- **框架**: Next.js 14 (App Router)
- **语言**: TypeScript
- **样式**: Tailwind CSS + shadcn/ui
- **状态管理**: Zustand
- **请求**: TanStack Query (React Query)
- **富文本**: Tiptap / Plate

### 部署
- **后端**: Docker + Docker Compose
- **前端**: Vercel / 自建服务器
- **CI/CD**: GitHub Actions

## 数据库设计

### 核心表结构

1. **用户表 (sys_user)** - 管理员和作者
2. **文章表 (article)** - 评测文章
3. **分类表 (category)** - 商品分类
4. **标签表 (tag)** - 文章标签
5. **文章标签关联表 (article_tag)**
6. **商品表 (product)** - 评测的商品信息
7. **评论表 (comment)** - 用户评论
8. **媒体表 (media)** - 图片/视频资源
9. **系统配置表 (sys_config)**

## 功能模块

### 前台功能
1. **首页** - 轮播图、热门评测、最新文章、分类导航
2. **文章列表** - 分类筛选、标签筛选、分页

### 后台管理功能

2. **文章管理** - 增删改查、富文本编辑、发布状态
3. **分类管理** - 多级分类、排序
4. **标签管理** - 标签云、关联统计
5. **商品管理** - 商品信息、关联文章
6. **媒体管理** - 图片上传、图库

## SEO 优化策略

1. **服务端渲染 (SSR)** - Next.js 14 App Router 默认支持
2. **动态 Metadata** - 每篇文章独立标题、描述、关键词
3. **结构化数据** - Schema.org Article 标记
4. **Sitemap** - 自动生成 XML Sitemap
5. **Robots.txt** - 搜索引擎爬虫配置
6. **Open Graph** - 社交媒体分享优化
7. **图片优化** - Next.js Image 组件自动优化
8. **URL 优化** - 语义化 URL，含文章标题关键词
